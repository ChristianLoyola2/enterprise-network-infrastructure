# Servicios de Red

## DHCP

DHCP permite asignar automáticamente parámetros de configuración IP a los dispositivos de las diferentes redes.

### Parámetros

- Dirección IP
- Máscara de red
- Gateway
- DNS

## DNS

DNS permite resolver nombres de host y servicios dentro de la infraestructura.

## Otros servicios

La topología contempla servicios adicionales asociados a la infraestructura empresarial:

- FTP
- Mail
- NTP

Estos servicios permiten representar diferentes funciones de infraestructura dentro del escenario de simulación.

## Validación

Se realizaron pruebas de:

- Asignación dinámica de direcciones.
- Resolución de nombres.
- Conectividad con servicios.
- Comunicación entre segmentos.

## Entorno

Proyecto desarrollado en Cisco Packet Tracer.
